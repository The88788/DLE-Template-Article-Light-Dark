# Article — адаптивный шаблон для DataLife Engine 20 (Light & Dark)

Современный универсальный адаптивный шаблон для DLE, изначально созданный для журналов, личных блогов, газет, новостных порталов и авторов. Благодаря гибкой блочной вёрстке на Bootstrap 5 он одинаково хорошо подходит и под классический блог/новостник, и под сайт-визитку небольшой компании, лендинг услуг или портфолио с разделом кейсов и новостей.

В комплекте — две полностью самостоятельные темы оформления с идентичной вёрсткой: светлая (Article) и тёмная (Article-dark), а на самом сайте есть переключатель между ними «на лету» — не нужно выбирать одну тему раз и навсегда.

## Что доработано в этой версии

- Обновление до актуальной DataLife Engine 20.0
- Обновлены сторонние библиотеки: Bootstrap, Font Awesome
- Карусели переведены с устаревшего Slick.js на Swiper — это сняло технический блокер и позволило безопасно перейти на jQuery v4
- Проверена совместимость со встроенной в DLE 20 микроразметкой Schema.org (Article/BlogPosting + BreadcrumbList) — включается штатными средствами админ-панели, без правок шаблона

## Авторизация через соцсети (VK / Yandex / Google)

Кнопки в окне входа (`login.tpl`) уже подключены к штатному механизму авторизации DLE — ничего в шаблоне менять не нужно. По умолчанию функция выключена и не настроена, поэтому кнопки не реагируют, пока не заполнены ключи.

Чтобы включить:

1. В админке: **Настройки → Система** — включить чекбокс «Разрешить авторизацию через социальные сети» (`allow_social`).
2. В админке: раздел **Соц. сети** (`admin.php?mod=social`) — включить нужные провайдеры (VK, Yandex, Google) и вписать Client ID / Client Secret.
3. Получить эти ключи в консолях разработчика:
   - **VK** — https://id.vk.ru/business/go/
   - **Yandex** — https://oauth.yandex.ru/client/new
   - **Google** — https://console.cloud.google.com/ (раздел «Credentials» / OAuth 2.0 Client IDs)
4. При создании приложения в качестве Redirect URI (URI перенаправления) указать:
   - `https://ваш-домен/index.php?do=auth-social&provider=vk`
   - `https://ваш-домен/index.php?do=auth-social&provider=yandex`
   - `https://ваш-домен/index.php?do=auth-social&provider=google`
5. Сохранить настройки — кнопки VK/Yandex/Google в окне входа заработают автоматически.

Ключи и настройка провайдеров также хранятся в файле `engine/data/socialconfig.php` — при желании их можно прописать туда напрямую, без админки.

## Слайдер и блоки новостей на главной — какие категории показывать

Все блоки на главной странице (`main.tpl`) и виджет в сайдбаре (`modules/sidebar.tpl`) берут посты через тег `{custom category="..." ...}` — параметр `category` задаёт ID категорий, из которых берутся публикации.

| Блок | Файл | Строка | Тег/шаблон |
|---|---|---|---|
| Слайдер (карусель вверху ленты) | `main.tpl` | 46 | `modules/slider`, `category="1,2,3"`, лимит 5 |
| «Главное» | `main.tpl` | 55, 58 | `modules/custom1`, `modules/custom1s` |
| «Актуальное» | `main.tpl` | 67–72 | `modules/custom2`, `modules/custom2s` |
| «Выбор редакции» (карусель) | `main.tpl` | 87 | `modules/custom3` |
| «Новые публикации» | `main.tpl` | 94 | `shortstory` |
| Сайдбар «Популярное» / «Случайное» | `modules/sidebar.tpl` | 12, 15 | `modules/topnews`, `category="1"` |

Чтобы вывести другие категории:

1. Узнать ID нужной категории в админке: **Управление → Категории** — ID указан в списке рядом с названием (или в URL при редактировании категории).
2. Открыть соответствующий файл (`main.tpl` или `modules/sidebar.tpl`) и заменить значение `category="1,2,3"` на нужные ID через запятую (например `category="4,7"` для одной категории — просто `category="4"`).
3. Значение нужно поменять в обеих темах (`Article` и `Article-dark`) — вёрстка идентична.

## Структура репозитория

```
Article/       — светлая тема
Article-dark/  — тёмная тема
```

Обе папки копируются в `templates/` вашей установки DLE как отдельные темы.
