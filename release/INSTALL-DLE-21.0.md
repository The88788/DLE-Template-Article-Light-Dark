# Установка Article для DLE 21.0

1. Сделайте резервную копию текущего каталога `templates/` сайта.
2. Скопируйте папки `templates/Article` и `templates/Article-dark` из архива в каталог `templates/` вашего сайта.
3. В панели управления DLE выберите `Article` как основной шаблон.
4. Не переименовывайте `Article-dark`: переключатель светлой и тёмной схем использует это имя.
5. Очистите кэш DLE и кэш браузера.

Актуальные версии: https://github.com/The88788/DLE-Template-Article-Light-Dark/releases
